# Shankmaster

1v1 knife-only arena game in the browser (phone + desktop). Three.js, no build step.

Run locally: `python3 devserver.py 8643` then open http://localhost:8643

- `js/game.js` — rounds, combat, bot AI
- `js/knives.js` / `js/textures.js` — knife models + procedural skins
- `js/characters.js` — cel-shaded characters
- `js/map.js` — London map + collision
- `js/audio.js` — synthesised SFX
- `js/ui.js` — menus, locker, store, chest opening, HUD
